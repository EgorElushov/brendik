# Руководство по использованию GIF реакций в Telegram Keyword Bot

## Что добавлено

В бот добавлена поддержка GIF-анимаций в качестве реакций на ключевые слова. Теперь бот поддерживает три типа реакций:
- 📝 **Текст** - обычные текстовые сообщения
- 🔊 **Голос** - голосовые сообщения  
- 🎬 **GIF** - анимированные GIF файлы

## Новые команды

### `/set_gif_reaction`
Устанавливает GIF реакцию для существующего ключевого слова.

**Использование:**
1. Введите команду `/set_gif_reaction`
2. Выберите ключевое слово из списка
3. Отправьте GIF анимацию
4. GIF реакция будет сохранена

### Обновленные команды

#### `/add_keyword`
Теперь при добавлении нового ключевого слова можно выбрать тип реакции:
- Текст
- Голос  
- **GIF** (новая опция)

#### `/set_reaction_type`
Позволяет переключать тип реакции между текстом, голосом и GIF (если соответствующие реакции установлены).

#### `/list_keywords`
Показывает тип реакции для каждого ключевого слова:
- 📝 Текст
- 🔊 Голос
- 🎬 GIF

## Как использовать GIF реакции

### Добавление нового ключевого слова с GIF реакцией

1. **Введите команду:** `/add_keyword`
2. **Введите ключевое слово:** например, "привет"
3. **Выберите тип реакции:** нажмите кнопку "GIF"
4. **Отправьте GIF:** загрузите GIF анимацию
5. **Установите вероятность:** введите число от 1 до 100

### Установка GIF реакции для существующего слова

1. **Введите команду:** `/set_gif_reaction`
2. **Выберите ключевое слово** из предложенного списка
3. **Отправьте GIF анимацию**
4. **Измените тип реакции:** используйте `/set_reaction_type` и выберите "GIF"

## Поддерживаемые форматы

Бот принимает GIF файлы в двух форматах:
- **Animation** - стандартные GIF анимации
- **Document** - GIF файлы, отправленные как документы (с MIME-type "image/gif")

## Обработка ошибок

Если GIF файл недоступен или произошла ошибка при отправке:
- Бот автоматически отправит текстовую реакцию вместо GIF
- В логах будет записана информация об ошибке

- **Вероятность:** 80%

## Технические детали

### Структура данных
```json
{
    "keywords": {
        "привет": {
            "reaction": "Привет!",
            "probability": 80,
            "reaction_type": "gif"
        }
    },
    "gif_reactions": {
        "привет": "BAADBAADGgADBREAAR4ysQABFJFuHwI"
    }
}
```

### Методы aiogram
- `message.animation.file_id` - получение ID GIF анимации
- `message.answer_animation(file_id)` - отправка GIF анимации
- `message.document.mime_type == "image/gif"` - проверка GIF документов

## Ограничения

1. **Размер файла:** Telegram имеет ограничения на размер файлов
2. **Формат:** Поддерживаются только GIF файлы
3. **Хранение:** GIF файлы хранятся по file_id в Telegram, не локально

## Обратная совместимость

Все существующие ключевые слова продолжают работать без изменений. Новое поле `gif_reactions` добавляется автоматически при первом запуске обновленного бота.
